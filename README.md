**Dynamic List Manager Application**

A simple React application that allows users to dynamically add items to a list. Users can type in text into an input field and click the "Add Item" button to add it to the list. The list will update in real-time, and the input field will clear after each submission. This project demonstrates basic React functionality, including state management, event handling, and rendering dynamic lists.

## Features

- Empty list on initial load.
- Input field for adding items to the list.
- "Add Item" button to submit new list items.
- Items are added to the list when the button is clicked.
- The input field is cleared after each item is added.
- If the input field is empty, no new items are added to the list.
- Customizable bullet points for list items.

**Usage**
-Upon loading the app, the list will be empty.
-Type text in the input field.
-Click the "Add Item" button to add the item to the list.
-The input field will automatically clear after each submission.
-If the input field is empty, no new item will be added to the list.
